# Установка и запуск

## Требования

- **macOS на Apple Silicon** (M1/M2/M3/...) — обязательно, т.к. генерация
  модели идёт через MLX (нативный фреймворк Apple для Metal GPU). На Intel
  Mac, Windows или Linux без Apple Silicon модель через MLX не запустится.
- **Python 3.12**.
- Рекомендуется **8+ ГБ свободной памяти** на момент запуска — модель
  (4-bit, ~1.8 ГБ) плюс эмбеддинги и векторная БД требуют заметный объём.
  Если на компьютере уже открыто много других приложений, лучше закрыть
  лишнее перед запуском (см. раздел "Возможные проблемы" ниже).

## Шаг 1. Клонировать репозиторий

```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd <ИМЯ_ПАПКИ_РЕПОЗИТОРИЯ>
```

## Шаг 2. Создать виртуальное окружение

```bash
python3.12 -m venv .venv
source .venv/bin/activate
```

Проверить, что активировалось нужное окружение:
```bash
which python
# должно показать путь внутри .venv, например .../rag_system/.venv/bin/python
```

## Шаг 3. Установить зависимости

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

Установка займёт несколько минут — `torch` и `mlx` весят по несколько сотен
мегабайт.

## Шаг 4. Запустить приложение

```bash
python app.py
```

При первом запуске модель `mlx-community/Qwen2.5-3B-Instruct-4bit`
(~1.8 ГБ) и эмбеддинг-модель `all-MiniLM-L6-v2` скачаются с Hugging Face —
это может занять несколько минут в зависимости от скорости интернета. При
повторных запусках модели уже в кэше (`~/.cache/huggingface`) и загрузка
займёт секунды.

В терминале появится строка вида:
```
Running on local URL: http://127.0.0.1:7860
```

Открыть этот адрес в браузере.

## Шаг 5. Загрузить тестовый документ

1. Во вкладке **"Документы"** загрузить файл `story_kazakh_spies.txt`
   (входит в репозиторий) и нажать "Загрузить в векторную БД".
2. Дождаться сообщения "Добавлено чанков: N" — база пуста после каждого
   перезапуска приложения, грузить документ нужно заново.
3. Перейти во вкладку **"Чат"** и задать вопрос, например: *"Кто обучал
   детей плаванью?"*

## Как прогнать эксперимент с атаками

Промпты атак лежат в `attack_prompts.md` (раунд 1, 10 прямых атак) и
`attack_prompts_round2.md` (раунд 2, 8 непрямых атак) — их можно вставлять
по одному во вкладку "Чат" вручную.

Чтобы прогнать все 18 атак автоматически против улучшенной конфигурации
(системный промпт + output-фильтр) и получить сырые + отфильтрованные
ответы:
```bash
python rerun_with_mitigation.py
```
Результат сохранится в `mitigation_rerun_results.json`.

## Возможные проблемы

**Сервер падает / не стартует из-за нехватки памяти.** Проверить своп:
```bash
sysctl vm.swapusage
```
Если `used` близко к `total` — закрыть лишние приложения (особенно другие
тяжёлые процессы) и перезапустить `python app.py`.

**При первом запуске видно предупреждение
`Warning: You are sending unauthenticated requests to the HF Hub`.** Это не
ошибка, просто Hugging Face напоминает, что без токена скорость загрузки
моделей ниже. Для работы это не критично.

**Нужно очистить базу и начать заново.** Либо удалить папку `chroma_db/`
вручную и перезапустить `app.py`, либо нажать "Очистить базу" во вкладке
"Документы".
